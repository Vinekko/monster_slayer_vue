## 📖 Introduction

**Monster Slayer** is an interactive web game where you take on the role of a hero fighting against a formidable monster. Manage your health, plan your attacks, and heal when necessary to survive the encounter.

The game features retro arcade aesthetics, real-time health bars, and a complete battle log to track every action in the match.

## ✨ Key Features

-   **Interactive Health Bars**: Visual feedback on player and monster health status.
-   **Turn-Based Combat**: Classic RPG style gameplay.
-   **Dynamic Battle Log**: Keeps a history of all combat events (Damage & Healing).
-   **Special Abilities**: Unleash powerful attacks with cooldown mechanics.
-   **Win/Loss States**: clear victory and defeat conditions.

## 🕹️ Controls

| Action | Description |
| :--- | :--- |
| **🗡️ Attack** | Deals standard damage to the monster. Always available. |
| **💥 Special Attack** | Deals heavy damage but can only be used every 3 rounds. |
| **❤️ Heal** | Restores a portion of health. Be careful, the monster still attacks! |
| **🏳️ Give Up** | Surrender the current match. |

## 🚀 How to Play

1.  **Clone or Download** this repository.
2.  Ensure you have the following files in the same folder:
    -   `index.html`
    -   `apps.js`
    -   `styles.css`
    -   `images/` folder
3.  Open `index.html` in your favorite web browser.
4.  Start fighting!

## 🛠️ Technologies Used

-   **HTML5** - Structure and layout.
-   **CSS3** - Retro styling and animations.
-   **Vue.js 3** - Game logic, state management, and DOM reactivity.
